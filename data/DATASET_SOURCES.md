# Dataset provenance and public-case import checklist

The bundled `benchmark_cases.json` contains **synthetic fixtures only**. It is not presented as a set of public GitHub or Stack Overflow cases, and its scores must not be described as real-world model accuracy.

For a public-data expansion, collect 30–50 error traces only after reviewing each source page, documenting its exact URL, root cause, verified resolution, and applicable license or terms. Prefer repositories with explicit licenses; check Stack Overflow content licensing and attribution requirements before redistribution. Keep a source manifest and do not scrape or redistribute content where terms do not permit it. Separate original excerpts from your own concise summaries and retain attribution. Re-run the same benchmark rubric for all three methods.
